# ailink v0.3 硬件设计说明（评审材料）

对应需求基线：`product.md` v0.3（2026-08-29）。本文记录从需求到原理图/PCB 的落地决策、器件定型、与基线的偏差及其理由。

## 2. 引脚映射与网表校验

原理图严格执行 product.md §5.1 引脚表（含 GPIO bit2 = PA0 迁移），全部 33 个已用引脚、19 个 NC 引脚逐一核对。自动化校验脚本 `scripts/verify_netlist.py` 将 §5.1 全表 + 保护拓扑（MCU→220 Ω→ESD→连接器）转为断言，当前结果：**全部通过（91 网络）**。ERC：**0 错误 / 0 警告**（`--severity-all`）。

## 3. 叠层与阻抗

| 层 | 用途 | 备注 |
| --- | --- | --- |
| L1 (F.Cu) | 信号 + USB 差分 | 90 Ω 差分：0.35 mm 线宽 / 0.15 mm 间隙 |
| L2 (In1.Cu) | 完整 GND 平面 | 无信号穿越（§4.14），差分参考层连续 |
| L3 (In2.Cu) | +3V3 平面 | 电源扇出经过孔直连 |
| L4 (B.Cu) | 低速信号 + GND 铺铜 | 背面整板 GND 铺铜（热焊盘连接），主 GND 平面仍为 In1 |

- 板厚 1.6 mm，叠层与阻抗见第 6 节（JLC7628）。L1 参考 L2，USB 差分目标 90 Ω ±10%（ER-07），线宽按叠层微调。
- USB 差分对内长度差以 `outputs/si-report.txt` 主路径值为准（U1→J1 A6/A7，已排除 TP6/TP7 与 J1 B6/B7 支路；过孔按 0.5 mm 等效；判定 ≤2 mm）。DM 侧 2 过孔造成的 4.84 mm 偏差已在 DP 走廊段以 2 个梯形蛇形（高 1.35 mm/倒角 0.25 mm）补偿，**实测主路径偏差 0.03 mm（PASS）**。主耦合段位于走廊区（In1 参考连续）；J1 出线端 B6/B7 为 Type-C 翻转短接支路。
- **HSE 晶振岛**：OSC_IN/OSC_XO/OSC_OUT 全程 F.Cu **0 过孔**（X1↔MCU 直连段 3–5 mm），R6 位于 X1 南侧，C10/C11 各配就近 GND 过孔直下 In1。晶振正下方 F 层无任何其他信号；B 层历史穿越（BOOT0 等）由完整 In1 GND 平面层间屏蔽（见偏差表）。
- D1（USBLC6）pin2 GND 为盘中孔，**制造时必须树脂塞孔+电镀盖帽（VIPPO）**。此为制造必要工艺，不是可选备注。

## 4. 与基线的工程偏差（不改变电气边界）

| 项 | 偏差 | 理由 |
| --- | --- | --- |
| D7 封装 | SMBJ→SMAJ5.0A (SMA) | KiCad 官方库有完整符号/3D；400 W 对 USB VBUS 浪涌充分 |
| D1 结电容 | USBLC6-2SC6 结电容 2.5–3.5 pF，高于基线 §4.3 "≤1 pF 量级" | USB 2.0 FS 12 Mbps 下 45Ω×3.5pF≈0.16ns 远小于边沿要求，该器件为 ST 官方 USB2.0 推荐 ESD；作为签核偏差记录，样机以枚举与眼图验证 |
| 信号 ESD | TPD4E05U06(USON) → SRV05-4(SOT-23-6) | 库件齐全、手焊友好；~3 pF/线(Semtech 原厂 IO-GND 典型值)满足 11.25 Mbaud 与 12 MHz SWD |
| R22↔R24、R15↔R16 | 物理位置互换（网络不变） | 消除交叉、缩短布线；BOM/丝印跟随位号无影响 |
| C14 | 翻至 B 面 U2 正下方 | U2.8→C14.1 直线约 2.95 mm（原 F 面距 VCC 16.7 mm 不合格），VCC/GND 均就近过孔入平面；板已有双面贴装，零工艺增量；两过孔按 VIPPO（见制板要求） |
| J4→D4/D5 ESD 通道分配 | D4/D5 八通道按 PCB 最短路径重新分配（原理图同步） | 连接器→ESD 焊盘路径由最差 28.2 mm/4 孔改善至 9.6–16.3 mm/≤1 孔（G2 9.6、G4/G5/G6 ≈10.2、G0/G1 ≈11、G3 ≈13、G7 ≈16 为几何绕行极限）；220 Ω 仍在 ESD 之后的 MCU 侧 |
| 晶振下方 B 层走线 | BOOT0 等在 X1 投影区 B 层通过 | 4 层板 In1 为无分割完整 GND 平面，F 层晶振回路与 B 层间有整层屏蔽；F 层晶振区无其他信号 |
| SPI2 走线长度 | SCK/MOSI/MISO 约 20–44 mm | SPI2 时钟 ≤22.5 MHz（周期 44 ns），44 mm ≈ 0.3 ns 传播延迟，时序余量充足 |
| C8/C9 (VDDA) | 距 U1 pin13 实测约 7.95/8.49 mm | VDDA 仅供 ADC 参考/模拟域（本版未用 ADC），FB1+1 µF+100 nF 岛经 In1 完整回流；HV-01 增加 VDDA 纹波实测 |
| 部分低速信号 | 0.15 mm 线宽（板规最小值） | 高密区通道宽度限制；均为 LED/GPIO/控制台等低速网络 |
| 背面元件 | CC 下拉、屏蔽 RC、R25/26、MCU 去耦 | 4 层板常规做法；贴片两面各一次回流 |
| 丝印位号 | 无源件位号不上丝印（装配用 Fab 层） | 板面 65×35 空间有限，保 MR-03 的信号名标注优先 |

## 5. 遗留事项（需样机验证，对应 §8/§9）

1. HV-01 LDO 温升与纹波实测（AP2112K-3.3 定型后回填壳温）。
2. HV-12 信号完整性：11.25 Mbaud UART 与 12 MHz SWD 连接器端波形。
3. HV-15 ESD 等级：SRV05-4/USBLC6/SMAJ 组合的接触放电等级确认。
4. 连接器直针/弯针（§9-3）按外壳方案二次确认；本版为直针。
5. USB VID/PID 维持 pid.codes 测试号（D-10），仅开发验证使用。

## 6. 制板要求（fab notes）

投板按嘉立创 JLC7628 四层叠层下单，并在订单中勾选阻抗控制。下列厚度为该叠层标称值（单位 mm），εr≈4.4。

| 层 | 材料 | 厚度 (mm) |
| --- | --- | ---: |
| Top (L1) | Cu 1 oz | 0.035 |
| PP | 半固化片 | 0.2104 |
| In1 (L2) | Cu 0.5 oz | 0.0175 |
| Core | 芯板 | 1.065 |
| In2 (L3) | Cu 0.5 oz | 0.0175 |
| PP | 半固化片 | 0.2104 |
| Bot (L4) | Cu 1 oz | 0.035 |

- **阻抗**：`USB_DP`/`USB_DM` 差分 90 Ω ±10%（L1 参考 L2）。按本叠层微调线宽/间距，以板厂阻抗计算或 coupon 实测为准；当前几何起点为 0.35 mm / 0.15 mm。
- **最小线宽/间距**：0.15 / 0.15 mm。
- **最小孔**：0.3 mm（成品孔径）。
- **VIPPO（树脂塞孔+电镀盖帽）位置清单**（制造必要工艺，须在订单中明示，共 4 处）：
  - D1 pin2 GND（盘中孔直连 In1 GND）
  - U1 pin16（CON_TX）盘中孔：pin16 南侧口袋已被 CON_RX/TGPIO6/VCAP/SWCLK 下潜孔占满，无常规 dog-bone 落点，保留盘中孔并与 D1 同批 VIPPO 加工（零增量成本）
  - C14 pad1(+3V3)/pad2(GND) 两只 0.5/0.3 mm 过孔：C14 位于 U2 腹地 B 面，孔缘与焊盘相切，按 VIPPO 处理防止回流吸锡
- **丝印**：最小字高 0.7 mm；接口针脚名优先于无源位号。J2–J5 逐针标注（J3/J4 西列 F 层、东列 B 层镜像 + F 层 A/B 列头；J5 背面逐针）；`3V3 ONLY`（F，J3 旁竖排）与 `NO PWR OUT`（B）为接口警示。J1（USB-C）本体悬出板缘导致 2 条丝印-板缘 warning，属封装固有，豁免。
