# ailink v0.3 制板必读（FAB NOTES）

随 Gerber 提交板厂，逐条确认。

## 1. 基本参数
- 板尺寸：65 × 35 mm（板框中心线），4 层，成品厚度 1.6 mm。
- 叠层：按 **嘉立创 JLC7628** 标准四层叠层（Top 1oz / PP 0.2104 / In1 0.5oz / Core 1.065 / In2 0.5oz / PP 0.2104 / Bot 1oz，εr≈4.4）。
- 最小线宽/间距：0.15 / 0.15 mm；最小成品孔径：0.3 mm。
- 表面处理：ENIG 或喷锡均可（建议 ENIG，USB-C 焊盘平整度更好）。

## 2. 阻抗控制（必选）
- `USB_DP` / `USB_DM`（L1 层）差分 **90 Ω ±10%**，参考层 L2（完整 GND）。
- 当前几何 0.35 mm 线宽 / 0.15 mm 间隙，按板厂阻抗计算微调线宽，附 coupon。

## 3. VIPPO——树脂塞孔 + 电镀盖帽（必做，共 4 处）
| 位置 | 坐标 (mm) | 说明 |
| --- | --- | --- |
| D1 pin2 | (110.36, 117.50) | USB ESD 阵列 GND 盘中孔，直连 In1 |
| U1 pin16 | (122.60, 121.90) | CON_TX 盘中孔 |
| C14 pad1 | (129.50, 128.05) | B 面去耦，+3V3 过孔与焊盘相切 |
| C14 pad2 | (127.82, 128.05) | B 面去耦，GND 过孔与焊盘相切 |

其余过孔常规工艺（盖油即可）。

## 4. 丝印
- 最小字高 0.7 mm，勿缩放。
- J1（USB-C）本体悬出板缘，其封装丝印与板缘重合的 2 条 DRC warning 为封装固有，**豁免**，不需修改。

## 5. 装配（如代贴）
- 双面贴装：B 面含 C3/C7/C14/R5/R25/R26/CC 下拉及 RGB 相关件。
- J6（1×4 焊盘）为 **DNP**：不焊接、不出坐标、不入 BOM。
- **D8 装配前置条件（必须）**：取得 FM-B3227RGBA-HG 正式规格书，核对共阳极性与 R/G/B 1–4 脚序和封装 `LED_RGB_1210` 焊盘映射一致后方可上料；若脚序不符，改用脚序一致的等效料或修版。
- BOM 见 `ailink-bom.csv`（含 MPN/Spec 列）。
