# ailink v0.3 设计复审报告（第三轮）

## 总体结论

**仍有条件通过。**

PCB 电气与布局主体已达到 v0.3 首板打样条件，第二轮两项 Major 均已实质整改，未发现新的电气 Blocker。独立复验结果：

- ERC：0 error / 0 warning。
- DRC：0 未连接、0 铜层/庭院违规；仅 J1 封装固有的 2 条丝印边缘豁免。
- `verify_netlist.py`：91 网络全部通过。
- USB 主路径：DP 52.11 mm、DM 52.14 mm，skew 0.03 mm，PASS。
- 最终 PCB SHA-256 前 16 位：`6a1c427915509a33`，与 SI 报告一致。

尚有两项不改 PCB 铜层即可关闭的发布条件：

1. 为 D8 提供 `FM-B3227RGBA-HG` 的正式规格书/采购来源，并确认 PCB 的 `pad4=共阳、pad1/2/3=R/G/B 阴极` 与实物完全一致。当前 BOM 自身仍写“装配前核对脚序”，因此尚不能视为已完成装配放行。
2. 更新 `DELIVERY.md`，将“可直接投板”的入口从旧 `ailink-gerbers.zip` 改为带 `FAB-NOTES.md` 的 `ailink-fab.zip`；同时在 FAB-NOTES 中补全 D1 pin2 的实际坐标 `(110.362, 117.500)`。

裸 PCB 数据本身可进入询价和板厂阻抗确认；包含贴片的正式下单包应在上述两项关闭后发布。

## 重布线引入问题检查

- J4 八路保护拓扑仍为 `MCU→220 Ω→ESD→连接器`，未发现通道串错或绕过 ESD。
- D4/D5 重新分配只使用器件等价 I/O 通道，不改变 GPIO bit0～7 的 MCU 与 J4 针脚定义。
- 新路径全部不超过 1 个过孔，未引入内层信号、未破坏 In1 GND，也未产生庭院/铜层 DRC。
- H4、J3/J4 丝印、D7、HSE、C14、J6 DNP、USB 蛇形补偿保持第二轮通过状态。
- `ailink-fab.zip` 内容为 4 铜层、2 阻焊、2 丝印、2 钢网、板框、钻孔、gbrjob 和 FAB-NOTES，共 14 文件，无原制造包的 Fab/Courtyard/User 冗余层。

## 结论

### 最终判定：仍有条件通过

**硬件 PCB 设计可接受，无需第三次大改版。** 在正式 PCBA/制造包放行前，仅需：

1. 完成 D8 规格书和脚序核验；
2. 修正 DELIVERY 投板入口并补 D1 VIPPO 坐标。

重复线段建议同时清理，但不影响本版 Gerber 的电气与可制造性。完成上述两项后，可按 `ailink-fab.zip`、JLC7628、90 Ω 阻抗控制及四处 VIPPO 要求投板；样机回来后继续执行 product.md HV-01～HV-15。
