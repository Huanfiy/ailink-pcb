## 3. 已验证的布局与布线事实

### 3.1 正反面局部重叠与器件分配

- 共 86 个封装位置：正面 15 个，背面 71 个。此统计包含维护触点、测试焊盘和不装配接口等，不等同于 86 颗实际贴装器件。
- MCU U1 与 Flash U2 的中心完全重合：均为 `(118.5, 111.0) mm`；U1 在正面，U2 在背面。
- R8.2 与 U2.3 的直线距离约 5.95 mm，尚未计入绕线长度。
- 当前使用贯通过孔；放置过孔时需要同时避开正反面焊盘以及其他铜、钻孔等障碍。

### 3.2 L3 的实际使用已超过“少量内部逃线”的描述

当前只读统计为：

| 项目 | 统计值 |
| --- | ---: |
| 全板走线段 | 1620 段 |
| 全板过孔 | 225 个 |
| L3 全部走线长度 | 约 419.5 mm |
| L3 信号走线长度 | 约 340.7 mm |
| L3 信号网络数量 | 36 个 |
| L3 信号线占全板信号线长度的比例 | 约 32.3% |

信号统计排除了 `GND`、`+3V3`、`+3V3_OUT`、`+5V_OUT`、`VBUS`、`VBUS_P`、`VDDA`、`VCAP`。

**32.3% 是走线长度占比，不是铜层面积利用率或可布通率。过孔数量也不是单独判定设计优劣的指标。** 这些数据主要说明：L3 已在承担相当一部分信号布线，后续需要明确规划信号走廊与电源连接区域，不能继续按基本完整的电源层来假设。

### 3.3 工艺规则与扇出空间的关系

- 最小线宽/间距：0.15 / 0.15 mm。
- 常规扇出过孔：铜盘 / 钻孔 0.5 / 0.3 mm。
- 工程最小钻孔：0.3 mm；最小过孔直径规则为 0.45 mm，但常规扇出脚本使用 0.5 mm。
- MCU 封装引脚节距为 0.5 mm，相关焊盘宽度为 0.3 mm。

仅按当前铜间距规则计算，两个不同网络的 0.5 mm 外径过孔，中心距至少需要约：

```text
0.5 mm 过孔外径 + 0.15 mm 铜间距 = 0.65 mm
```

因此不能简单按照 MCU 的 0.5 mm 引脚节距给每个引脚排一列这种过孔，需要错列、不同方向引出，并给贯通孔保留正反面共同可用的位置。

这说明扇出规划重要，并不意味着 0.15 mm 间距本身不合理，也不意味着缩小线宽就能解决所有障碍。

## 4. 原因分析

### 4.1 布局检查偏向“放得下”，未充分优化“走得通”

**证据：** `scripts/gen_pcb.py` 的摆放算法检查封装边界、孔位、预留区域等冲突，并主要按接近预设坐标评分。代码明确说明，放置检查不宣称布线可行。

**判断：** 正反面同中心的 MCU / Flash，加上背面密集的无源与保护器件，使一些需要跨层的信号找不到方便的过孔落点。R8 到 Flash 的连接距离也提示，个别局部器件组没有围绕连接路径形成紧凑布局。

**边界：** 正反面器件重叠并非天然错误；背面器件多也不构成不可布通证明。但具体中心坐标、朝向和无源件排列应当可优化，而不应被当作不可改变的产品要求。

### 4.2 普通信号扇出锁定过早

**证据：** `scripts/fanout_mcu_product.py` 找到局部合法的直线与过孔后，会锁定这些对象。当前普通 GPIO、LED、SPI 等信号也存在锁定扇出。

**判断：** “这一小段不碰铜”不等于“从这个过孔能够到达最终目标”。过早固定扇出位置，会把局部选择变成后续布线的硬障碍。

**改进方向：** 区分电气上需要保护的关键结构，与仅为自动布线预留的普通扇出。普通信号应允许移动过孔、重排引出方向和局部拆线重布。

### 4.3 局部补线搜索不能证明整个设计不可布通

**证据：** `scripts/finish_routes.py` 在既有铜结构上寻找连接，采用逐网、分级网格搜索和有限次重试。虽然已加入实际焊盘铜形状、0.025 mm 网格和几何校验，但它不是器件摆放与布线的全局联合优化器。

**判断：** 继续在既定布局和大量固定铜上补剩余空隙，容易陷入局部解。此前拆线重布尝试也出现了“接通一个网，却打断另一个网或电源平面”的情况。

**实现责任：** 前一步的固定摆放、锁定扇出和补线策略需要调整，不能把自动搜索失败简单归因于用户提出了不合理的产品约束。

### 4.4 电源区域与信号通道需要协同规划

**证据：** L3 已承担 36 个信号网络；本轮收尾中曾出现新信号走线割裂 +3V3 填铜，需要恢复连接。

**判断：** 这不仅是“再补几根飞线”的问题，也涉及层分工与电源连接路径。应先规划可连续供电的区域和必要连接，再安排信号走廊，避免反复切断和补桥。

**不能由此推出：** L2 地参考应当随意让给信号，或当前项目必须改成六层。

## 5. 是否需要放宽约束？

| 约束 | 评估 | 建议 |
| --- | --- | --- |
| 42 × 22 mm、四层 | 紧凑，确实增加难度；尚未证明不可完成 | 第一轮重布局继续保留 |
| 接口功能、脚序、保护拓扑 | 属于产品功能和可靠性基线 | 保留，不以删减功能换取布通 |
| USB / 尾针位置、LED 对齐等外观锚点 | 有明确产品价值 | 尽量保留，优先优化内部结构 |
| MCU / Flash 的具体中心、朝向 | 对当前局部拥塞影响较大 | 优先允许评估调整，不坚持正反面同中心 |
| 背面电阻、电容、保护器件的具体坐标 | 很多属于实现选择 | 按连接关系成组重排；必要时评估少量无源件换面 |
| 普通信号扇出和已有走线不许移动 | 额外限制了实现自由度 | 解除不必要的锁定，允许局部重布 |
| 0.15 / 0.15 mm 线宽/间距 | 稳健的工程选择，不是极端要求 | 先保留，必要时再局部细化 |
| 0.5 / 0.3 mm 常规过孔 | 合理，但对细间距扇出较占空间 | 作为第二阶段工艺优化项 |
| 连续地参考、USB 回流、时钟保护 | 不宜为布通而牺牲 | 保留电气要求，不把旧几何坐标本身当作绝对要求 |
| 不使用未经确认的盘中孔 / VIPPO | 避免引入未确认的制造装配工艺 | 保留；改变前须单独评估并确认 |
| 未连接清零后才出制造包 | 必要的验收门禁 | 不放宽 |

### 可评估但尚未批准的工艺选项

若在重布局和重新扇出后仍有明确的局部瓶颈，可研究例如：

- 局部 0.125 mm 信号走线及与所选工艺匹配的间距。
- 局部 0.45 / 0.20 mm 铜盘 / 钻孔的过孔。

**上述是候选方案，不是当前工程已允许或板厂已确认的参数。** 0.20 mm 钻孔低于本工程当前的 0.30 mm 最小钻孔规则。采用前必须确认板厂、板厚、铜厚、环宽、孔到铜、孔间距、阻焊和订单条件，并同步更新实际几何、规则及制造说明。

不得只降低 DRC 数值，或缩小元器件实际焊盘来消除冲突。电源走线与 USB 阻抗几何也不应跟随普通信号一起缩小。

## 6. 建议的后续处理顺序

### 阶段 A：不改变产品定义，重新规划局部布局

1. 在隔离目录建立候选，保留当前主 PCB 及可追溯基线。
2. 第一轮保留外形、层数、接口脚序、功能和现有制造规则。
3. 评估移动或旋转背面 Flash，不要求其中心与 MCU 重合。
4. 重排 R8 / R9、D4 / D5 与周围串阻，以实际连接路径和扇出空间为优先，而不是仅按空位填充。
5. 为 MCU 普通信号重新分配引出方向与错列过孔，允许拆除不合适但局部合法的旧扇出。
6. 明确 L3 的信号走廊和电源连接区域，保护 USB 背面参考区与 L2 地参考。
7. 以完整局部器件组恢复连通为目标，不接受仅把未连接问题转移到其他网络的方案。

如果移动 MCU、晶振岛或相关器件，应同步检查 `product_config.py`、`fanout_product.py`、`astar_router.py`、`check_product.py` 等中的坐标和禁布区域。不能移动实际器件后仍用旧区域进行保护或验收。

### 阶段 B：有针对性地优化局部工艺

只有阶段 A 仍存在明确瓶颈时，再比较局部细线、小孔方案。每个方案都要说明：改善哪个通道、影响哪些电气与制造条件、由哪些检查和板厂确认支撑。

### 阶段 C：最后讨论外形或层数变化

在可控重布局与工艺候选仍不能满足要求时，再讨论增加板宽或改六层。增加层数不会自动消除表面焊盘和贯通孔投影的冲突，因此不能替代局部布局优化。

## 7. 验收与停止条件

候选写回主工程前，至少满足：

- 不改变未获批准的产品定义、接口脚序和保护拓扑。
- 当前问题相关的未连接、悬空过孔、短路及间距问题清零；其他现有检查不退步。
- 不为通过门禁而新增忽略项或不受支持的豁免。
- 重填铜后的原生 DRC、ERC、原理图一致性、产品检查和 USB 几何检查全部通过。
- 电源平面连通和关键回流路径得到复查，不能只看网络名称相同或存在过孔。
- 孔与 SMT 焊盘关系、实际工艺能力得到检查；如改变工艺，制造说明同步更新。
- 检查报告与实际源文件 SHA-256 一致，再允许生成制造包。

数字检查通过仍不等同于量产就绪。实际叠层阻抗、D8 正式脚序、J2 夹板装配、电源/温升/反灌、USB 挂起电流和样机通信测试等边界仍按 `product.md`、`DELIVERY.md` 和 `docs/design/fab-notes.md` 执行。
