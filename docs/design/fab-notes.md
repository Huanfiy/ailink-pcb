# ailink v0.4 制造与装配条件

本文随制造包一起交付（`scripts/export_all.sh fabrication` 会把它复制为 `outputs/FAB-NOTES.md` 打入 ZIP）。工程状态与阻塞项以 [DELIVERY.md](../../DELIVERY.md) 为准，本文只写板厂与装配方需要的条件；旧版 65 × 35 mm 制造文件、VIPPO 坐标和评审结论不适用于本版。当前数字检查结果见本地 `outputs/verification.json`；样机验证与器件装配定型仍需单独完成。

## 板规格

- 板框 42 × 22 mm、R2，无安装孔；四层，成品厚度 1.6 mm。
- 黑色阻焊、白色丝印、ENIG；双面 SMT，电阻及 100 nF 电容主要采用 0402。
- 最小线宽/间距 0.15/0.15 mm；普通过孔铜盘/成品孔 0.5/0.3 mm，USB 为 0.6/0.3 mm；铜到板边 0.3 mm。
- L1 为正面信号，L2 完整 GND，L3 为 +3V3、内部信号及背面 USB 专用 GND 区，L4 为背面信号。
- 工程中的层厚用于预览，不是已获板厂确认的叠层。USB F 段参考 L2、B 段参考 L3 地区；90 Ω ±10% 需实际叠层场求解与样机/coupon 验证。部分连接器和 ESD 扇出未耦合，长度检查不能替代阻抗验证。

## 装配

- J2 为 2×6 / 2.54 mm 双排直针夹板安装，F/B 独立表面焊盘，无板边电镀。双面 SMT 完成后，用夹具居中、定深、保持平行，再二次焊接；J2 不出锡膏、不进入贴片坐标。
- TSW-106-07-L-D 为候选，需要核对针尾、插接长度、方针截面、镀层和公差。1.6 mm PCB 在 1.90 mm 名义针间净空内每侧约有 0.15 mm 间隙，必须用同板厚试片验证焊接。
- J3/J4 仅保留两组各四个 1.0 mm GPIO 镀通孔，排针 DNP。其串阻和保护器件正常贴装。
- J5/J6 为背面探针触点；TP1/TP6/TP7 为测试焊盘；均不作为贴片器件供料。
- D8 上料前取得正式规格书，核对共阳极性、R/G/B 脚序和焊盘映射。USB 与 J2 的预览模型仅供外观检查，不能代替原厂尺寸图。
- 当前候选检查未发现 SMT 焊盘内或距焊盘 0.025 mm 以内的过孔钻孔开口，过孔均设置双面盖油；本轮未引入 VIPPO。禁止沿用旧版四处 VIPPO 清单，后续布线修改必须重新检查孔到焊盘的关系。

## 样机前后核查

额定输出目标为 3.3 V / 100 mA、5 V / 150 mA。需验证总 USB 电流、枚举前/挂起/突入、LDO 温升、限流恢复和反灌；TPS2553 的反向电压保护存在检测响应时间，不能当作瞬时理想隔离。当前固件关闭目标输出后仍保持 MCU 180 MHz，尚未闭环 USB 挂起低功耗。

复测 USB 正反插、双 UART 及四灯、SWD、GPIO、Flash、无按键升级和工厂救砖；核对 USB 插头、选装 GPIO 母壳、夹板针与 LED 可见性。正式销售前使用已获分配的产品 VID/PID，现有测试号不是量产标识。
